Electromagnetic Foundations

Governing Physics & Analytical Array Factor

First-Principles Rigor

Geometry & Phase Shift

  • Orientation: Line source along z-axis. θ measured from positive array axis (0° to 180°).
  • Wave Number: k = 2π / λ, where λ = c / f.
  • Spatial-Electrical Phase:
    ψ = k·d·cos(θ) + β
  • Progressive Phase β:
    β = -k·d·cos(θ₀)
    Applied per-element to steer peak to θ₀.

Array Factor Solutions

  • Complex Summation:
    AF(θ) = Σ aₙ · e^(j·n·ψ)
    Supports arbitrary amplitude tapers aₙ.
  • Closed-Form (Uniform):
    |AF| = |sin(Nψ/2) / sin(ψ/2)|
  • Power & Decibel Conversion:
    P(θ) = |AF_norm|²
    AF_dB = 20·log₁₀|AF_norm(θ)|
    Clipped at floor (-100 to -20 dB).

Singularity Resolution

  • Indeterminate Form: When ψ → 2mπ, both numerator and denominator vanish (0/0).
  • L'Hôpital Limit:
    lim_{ψ→2mπ} |AF| = N
  • Precision Guarantee: Identifies |sin(ψ/2)| < 1e-12 and assigns N. Cross-verified with summation error < 1e-10.
  • Safe Decibels: Clamped to 1e-15 floor before log₁₀ to prevent -inf crashes.

Experimental Validation

Verification of Key Electromagnetic Phenomena

Benchmark Cases
Exp 1: Element Count Scaling N = 2, 4, 8, 16, 32, 64

• Main beam narrows proportionally to 1/N (HPBW drops from ~50° to ~3.2°).
• Directivity scales linearly with element count N.
• First sidelobe level remains locked at theoretical -13.26 dB for uniform arrays.
• Visible null count equals exactly N - 1.

Exp 2: Spacing & Grating Lobes d/λ = 0.1 to 2.0

• For d < 0.5λ: Single broadside beam with zero grating lobes.
• At d = 1.0λ: First grating lobes emerge at end-fire angles (0° & 180°) at 0 dB.
• For d > 1.0λ: Severe spatial aliasing introduces multiple secondary major maxima.
• Grating-free condition verified: d/λ < 1 / (1 + |cos θ₀|).

Exp 3: Phased Beam Steering θ₀ = 0° to 180°

• Linear feed phase β = -kd cos(θ₀) shifts the main beam electronically.
• Beam broadening observed away from broadside: HPBW(θ₀) ≈ HPBW_broadside / sin(θ₀).
• Effective aperture length contracts from L to L·sin(θ₀).
• End-fire configurations (0° and 180°) produce wide conical beams.

Exp 4: Amplitude Window Tapering Uniform vs Hann vs Binomial

• Uniform: Narrowest beam (HPBW = 12.8°), highest sidelobes (-13.26 dB).
• Hann (Cosine): Sidelobes suppressed to -31.5 dB; HPBW widens by ~35% (17.5°).
• Binomial: Complete elimination of sidelobes for d ≤ 0.5λ at the cost of broad beam.
• Proves the fundamental engineering trade-off: resolution vs. interference rejection.
